# 南京明城墙 · 知识交互图谱

公开仓库：https://github.com/MRSHDER/nanjing-city-wall-knowledge

部署网址：https://mrshder.github.io/nanjing-city-wall-knowledge/

面向南京城墙博物馆公共触控屏的游戏化知识探索展项。

对应 2026「智说南京人文」AI 应用征集：南京城墙博物馆｜明城墙数字活化｜城墙知识交互图谱。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 部署

推送 `main` 后由 GitHub Actions 自动发布到 GitHub Pages。

若首次未出站，到仓库 Settings → Pages → Build and deployment → Source 选 GitHub Actions。
